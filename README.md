# ✦ Arcane Survivors

A fast, browser-based fantasy survival game about **magic, monsters, and staying alive**.

You are an arcane mage surrounded by creatures from the shadows. Move, aim, cast powerful spells, level up, and see how long you can survive.

## 🎮 Play

**GitHub Pages:** this game is designed to run as a static site, so it needs no server or build step.

1. Put `index.html`, `style.css`, and `game.js` in your repository root.
2. Open **Settings → Pages** in GitHub.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save, then open the GitHub Pages URL GitHub provides.

## 🪄 Controls

| Input | Action |
| --- | --- |
| **WASD / Arrow Keys** | Move |
| **Shift** | Sprint |
| **Mouse** | Aim |
| **Left Click / 1** | Fireball — rapid ranged damage |
| **2** | Arcane Nova — area damage |
| **3** | Blink — teleport forward |
| **4** | Frost Bolt — damage + slow |
| **5** | Chain Lightning — strikes several enemies |
| **6** | Meteor — delayed massive area blast |
| **7** | Arcane Ward — blocks incoming damage |
| **P** | Pause |
| **R** | Restart after defeat |

## 👹 Monsters

Three monster types can appear during a run:

- **Imps** are quick and aggressive.
- **Ghouls** are slower but tougher.
- **Wraiths** are fast supernatural hunters.

Monsters scale as the run gets harder. Defeat them to gain XP, increase your level, restore your magic, and push your score higher.

## ✨ Features

- Canvas-based combat with no libraries or frameworks
- Mouse aiming and responsive movement
- Seven spells with distinct roles
- XP and leveling system
- Multiple monster types
- Particle effects, spell glow, hit effects, screen shake, and animated UI
- Responsive layout for desktop and smaller screens
- Fully static and GitHub Pages friendly

## 🛠️ Run locally

Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
