# Arcane Survivors V4

A browser-only fantasy magic survival game for GitHub Pages.

## V4 improvements
- 15 spells now have different visuals and different mechanics/damage.
- 5 enemy types have different bodies, sizes, speeds, health, and attacks.
- Dread Lord and Ancient Dragon boss fights with large health bars.
- Wave progression and level rewards.
- Fireball explosions, ice crystals, chained lightning, falling meteors, gravity orb, tornado suction, blizzard fields, storm strikes, healing rings, and a screen-wide Apocalypse.

## Controls
WASD / Arrows = Move  
Shift = Sprint  
Mouse = Aim  
Left Click = Cast selected spell  
1-9, 0, Q, E, F, G, H = Select and cast spells  
P = Pause  
R = Restart after defeat

## GitHub Pages
Replace your existing `game.js`, `index.html`, and `style.css` with the V4 files in this folder, then commit to the `main` branch.
